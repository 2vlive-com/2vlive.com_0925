# โปรตุเกสเฉือนเวลส์ 1-0 ประเดิมสามแต้ม เนชั่นส์ ลีก 2026/27
โปรตุเกส แชมป์เก่า เปิดบ้านเฉือนเอาชนะ ทีมชาติเวลส์ 1-0 ในศึกฟุตบอล ยูฟ่า เนชั่นส์ ลีก เอ กลุ่ม 4 นัดเปิดสนาม ฤดูกาล 2026/27 เก็บสามคะแนนได้ตามเป้าหมาย แม้ คริสเตียโน่ โรนัลโด้ จะส่งบอลเข้าสู่ก้นตาข่ายได้ในช่วงครึ่งหลัง แต่ถูก VAR ตรวจพบว่าอยู่ในตำแหน่งล้ำหน้าเกมที่รังเหย้าของ โปรตุเกส เจ้าถิ่นเป็นฝ่ายครองเกมและเดินหน้ากดดันใส่ทีมเยือนอย่างต่อเนื่อง ก่อนมาได้ประตูขึ้นนำในนาทีที่ 22 จากจังหวะที่ นูโน่ เมนเดส พาบอลขึ้นทางฝั่งซ้าย ก่อนจ่ายเข้ากลางให้ ชูเอา เฟลิกซ์ แต่งบอลหาช่องบริเวณหน้ากรอบเขตโทษ แล้วซัดด้วยขวาส่งบอลเสียบเสาเข้าไปอย่างเด็ดขาด โปรตุเกสนำ 1-0
